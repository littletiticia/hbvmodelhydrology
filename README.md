This Python script provides an educational implementation of a simplified HBV hydrological model designed to simulate daily river discharge using precipitation, temperature, and potential evapotranspiration data. The model calculates the watershed's water balance through four sequential conceptual modules: a degree-day method for snow accumulation and melt, a non-linear soil moisture routine that calculates effective precipitation based on field capacity, a dynamic evapotranspiration adjustment, and a routing phase that uses two interconnected reservoirs to compute surface runoff, interflow, and baseflow. Beyond running the daily simulation, the code evaluates its accuracy against observed flow using statistical metrics like RMSE and the Nash-Sutcliffe efficiency coefficient, and it concludes by running a parameter sensitivity analysis to identify the optimal calibration for the system.
